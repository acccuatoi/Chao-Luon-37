## 📋 Danh sách kiểm tra trước khi nộp (Checklist)

### 1. GitHub Repository
- [ ] Repository đã được chuyển sang chế độ **Public** (Công khai).
- [ ] Code nguyên mẫu hoạt động được (Working Prototype) nằm trong repo.
- [ ] Có file video demo `.mp4` nằm trong repo (kích thước **dưới 100MB** - giới hạn của GitHub).
- [ ] Đã thêm badge TideCloak ở đầu file `README.md`:
  ```markdown
  [![Built with TideCloak](https://tide.org/badges/built-with-tidecloak.svg)](https://tide.org/tidecloak?utm_source=github&utm_medium=readme&utm_campaign=unlocked)
  ```

### 2. Nội dung README.md (Bắt buộc dưới 300 từ cho phần Project Overview)
README phải trả lời đầy đủ 5 câu hỏi tương ứng với 5 tiêu chí chấm điểm:
- [ ] **1. Vision & originality (25%)**: Ý tưởng có mới lạ, đột phá, giải quyết bài toán độc đáo không?
- [ ] **2. Trust constraint insight (20%)**: Đã chỉ rõ nút thắt về "niềm tin / quyền lực đơn phương" đang kìm hãm điều gì ngày nay?
- [ ] **3. Value & impact (20%)**: Ai hưởng lợi và giá trị thực tế mang lại là gì?
- [ ] **4. Why TideCloak matters (20%)**: Làm rõ tại sao TideCloak (Emergent Authority, phân quyền không cần master key) là yếu tố cốt lõi giúp hiện thực hóa ý tưởng?
- [ ] **5. Prototype & storytelling (15%)**: Bản prototype trình diễn tương tác then chốt nào để giám khảo chú ý?
- [ ] Đã kiểm tra tổng số từ phần overview **≤ 300 words**.
- [ ] Có phần hướng dẫn cài đặt và chạy ứng dụng (`## Setup`).

### 3. Demo Video (2 phút)
- [ ] Định dạng: File `.mp4`.
- [ ] Dung lượng: **< 100 MB**.
- [ ] Thời lượng: Khoảng **2 phút** (không quá dài).
- [ ] Đầy đủ 4 phần theo khuyến nghị của Tide:
  1. **The possibility** (Ý tưởng bạn xây dựng là gì?)
  2. **The constraint** (Rào cản niềm tin/bảo mật nào đang ngăn cản nó?)
  3. **The prototype** (Chiếu giao diện demo thực tế hoạt động, vai trò của TideCloak)
  4. **What changes** (Điều gì trở nên khả thi cho người dùng khi loại bỏ quyền kiểm soát đơn phương?)

### 4. Nộp qua Google Form
- [ ] Điền link GitHub repository: `https://github.com/acccuatoi/Chao-Luon-37`
- [ ] Kiểm tra lại quyền truy cập (mở link ở trình duyệt ẩn danh xem có xem được code và video không).
- [ ] Nhấn gửi trước giờ đóng cổng nộp bài.

## ⚠️ Những điều cần tránh (Pitfalls to Avoid)
> *Trích dẫn từ ban tổ chức Tide:*  
> **"Don't make the project mainly a login demo, a security tool or a generic access-control dashboard. Show what becomes newly possible for the people using it."**  
> *(Không biến dự án thành một màn hình đăng nhập đơn thuần, một công cụ bảo mật chung chung hay dashboard phân quyền thông thường. Hãy chứng minh điều mới mẻ nào trở nên khả thi cho người dùng!)*
